# Construction Site Supervision Test

This repository provides a simple command-line quiz for testing basic knowledge of construction site supervision.

## Requirements

- Python 3.8+
- [fpdf2](https://pypi.org/project/fpdf2/) for generating PDF reports

Install dependencies with:

```bash
pip install fpdf2
```

## Usage

Run the quiz from the command line:

```bash
python3 construction_test.py
```

After completing the multiple choice questions, your score will be displayed and a `test_report.pdf` file containing a detailed breakdown of each question, the correct answer, and a short explanation will be generated.
